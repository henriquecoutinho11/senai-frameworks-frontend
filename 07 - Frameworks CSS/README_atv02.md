# Box Model & Flexbox

Interface visual desenvolvida para a aula 07 do SENAI, demonstrando conceitos de Box Model e Flexbox em uma galeria com 20 elementos responsivos.

## Tecnologias

- HTML5
- Tailwind CSS via CDN
- Google Fonts: Space Grotesk e DM Mono

## Como executar

Não é necessário instalar dependências. Abra o arquivo `index.html` diretamente no navegador ou use uma extensão como o Live Server no VS Code.

É necessária uma conexão com a internet para carregar o Tailwind CSS e as fontes externas.

## Recursos

- Layout responsivo para desktop e dispositivos móveis
- Galeria com 20 cartões coloridos
- Efeitos de hover nos cartões
- Tipografia personalizada
- Estilização feita exclusivamente com classes utilitárias Tailwind no HTML
