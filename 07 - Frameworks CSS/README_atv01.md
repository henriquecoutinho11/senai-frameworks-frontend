# Projeto CSS

Projeto desenvolvido para a atividade de CSS do SENAI, utilizando HTML e CSS externo.

## Objetivo

Praticar o Box Model e o Flexbox por meio de uma página responsiva com 20 elementos visuais.

## Estrutura

- `index.html`: estrutura semântica da página e os 20 cartões.
- `style.css`: estilos, Box Model, propriedades Flexbox e responsividade.

## Recursos utilizados

- HTML5
- CSS3
- CSS externo com a tag `link`
- Content, padding, border e margin
- Flexbox
- Media queries para telas menores

## Como executar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências ou iniciar um servidor.

## Resultado

A página apresenta uma composição com cabeçalho, seção introdutória, 20 cartões organizados com Flexbox e rodapé. O layout se adapta a computadores, tablets e celulares.
