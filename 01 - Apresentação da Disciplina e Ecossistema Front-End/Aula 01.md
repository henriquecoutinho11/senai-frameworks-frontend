# Contexto da Disciplina

## Requisito Estratégico

Fundamental para a competitividade empresarial.

## Arquitetura de Software

Como diferentes partes se interligam para melhoria das aplicações.

Atualmente, boa parte das aplicações web modernas utilizam algum framework Front-end. Empresas precisam desenvolver interfaces rápidas, organizadas e fáceis de manter.

---

# O que é Desenvolvimento Front-end?

O Front-end é a camada de uma aplicação com a qual o usuário interage diretamente.

É responsável por:

- Criação das interfaces
- Organização visual dos elementos
- Experiência do usuário
- Comunicação com os sistemas responsáveis pelo processamento dos dados

# Introdução ao JavaScript (Vanilla JS)

## O que é?

Linguagem de script interpretada, essencial para o desenvolvimento Front-end.

## Vanilla JS

JavaScript puro, sem dependências externas, base para todas as abstrações.

## Importância

Permite manipulação de páginas, comunicação com servidores e lógica de interface.

# Desenvolvimento do Projeto

A avaliação final será composta por uma documentação completa do projeto, elaborada como um "mini TCC", contendo:

- Concepção inicial
- Planejamento
- Execução
- Resultados
- Desafios
- Soluções adotadas
- Análise crítica

---

# Apresentação do Projeto

A avaliação será baseada na entrega e apresentação do projeto, considerando:

- Processo de gestão
- Organização do backlog
- Desenvolvimento das páginas
- Benchmarking
- Implementação das funcionalidades
- Comparação com soluções do mercado
